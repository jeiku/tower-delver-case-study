# Tower Delver Product Case Study

Tower Delver is an original party-based JRPG roguelite currently in active development.

This case study covers the product strategy, human-directed AI workflow, quality gates, playtesting, and owner-led decisions used to take the game from concept to a tested, playable vertical slice.
